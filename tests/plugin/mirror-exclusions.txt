# Plugin assets that are deliberately NOT mirrored from templates/core/.
#
# THE POPULATION IS EVERY FILE UNDER plugin/ — not the Markdown ones. That is a
# written decision and it lives here, where it is visible, rather than in a glob
# in the test, where it would be silent. The first draft of monorepo#32's plan
# scoped the sweep to `*.md` and recorded the non-Markdown case as a *future*
# risk; there were four such assets at the time, and one of them —
# `plugin/hooks/session-start` — is the plugin's only executable, running on
# every consumer session start. It also has no extension, so even widening the
# glob to `*.md`/`*.json`/`*.sh` would still have missed it. A file type is not
# a reason; a fact about the file is.
#
# FORMAT: <path><whitespace><reason>
# An entry with no written reason is NOT an entry — the same refusal
# `scripts/smoke/coverage-allowlist.txt` applies, and the same one
# `scripts/check-scaffold-drift.sh` applies in the monorepo. Three readers, one
# rule; see that plan's §5 and §9 for why they are not unified and what replaced
# "a grep for the sentence finds all three".
#
# An entry naming a file that no longer exists is reported as stale. An
# exclusion that excuses nothing while looking like it does is the shape this
# whole ticket is about.

plugin/README.md  the plugin's own front door — describes installing the plugin, which no scaffolded project ever sees, so nothing under templates/core/ can be its source
plugin/hooks/session-start  plugin-only entry point; the Claude Code SessionStart hook that injects the bootstrap skill. No templates/core/ counterpart exists — the scaffolded harness wires its hooks through .claude/settings.json instead
plugin/hooks/hooks.json  declares what session-start runs, for the plugin loader only; scaffolded projects declare hooks through the harness, not through this file
plugin/hooks/hooks-cursor.json  the same declaration for Cursor's loader; same reason
plugin/.claude-plugin/plugin.json  the plugin manifest. Generated shape, asserted by its own test below for name/description/version, and there is no template that could be its source
